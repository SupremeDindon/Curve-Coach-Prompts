# Curve Coach

Curve Coach is a practice app for first-year microeconomics students
learning supply and demand.

Students practice movement along a curve, single curve shifts,
and shifts of both curves. The app gives feedback, allows retries,
and summarizes concepts to review.

## Purpose of this repository

This repository tracks the AI instructions developed and tested
for the ARIN 121 final project.
